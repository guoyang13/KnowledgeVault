# 动态代理是什么？

> 关联：[[22-Spring-AOP代理创建详解]] · [[15-工厂Bean-FactoryBean接口体系详解]] · [[100-Q&A/DDD分层-编译时运行时与Spring装配]]

---

## 一句话

**动态代理**：在**运行时**生成一个「替身对象」，它**实现/继承**目标类型，但**方法调用会先经过一层拦截逻辑**，再决定是否、如何调用真正的目标。

---

## 和静态代理对比

| | 静态代理 | 动态代理 |
|---|---------|---------|
| 代理类 | 编译期手写 `UserServiceProxy implements UserService` | 运行时自动生成 |
| 代码量 | 每个接口/类都要写一份 | 一套通用机制复用 |
| 典型用途 | 简单包装 | AOP、MyBatis Mapper、RPC 客户端 |

---

## Java 两种常见实现

### 1. JDK 动态代理（基于接口）

```java
UserService proxy = (UserService) Proxy.newProxyInstance(
    loader,
    new Class<?>[] { UserService.class },
    (proxyObj, method, args) -> {
        System.out.println("before");
        Object result = method.invoke(target, args);
        System.out.println("after");
        return result;
    }
);
```

- 只能代理**接口**
- 类名类似 `$Proxy12`
- 核心：`Proxy` + `InvocationHandler`

### 2. CGLIB 动态代理（基于子类）

- 字节码生成**目标类的子类**（如 `UserService$$EnhancerByCGLIB$$xxx`）
- 可代理**无接口的类**
- 不能代理 `final` 类/方法

Spring AOP：**有接口优先 JDK，否则 CGLIB** → [[22-Spring-AOP代理创建详解#九、JDK vs CGLIB 速查]]。

---

## 调用链

```text
客户端
  → proxy.save()          // 以为在调 UserService
  → InvocationHandler     // 或 CGLIB MethodInterceptor
  → [事务 / 日志 / 权限 … 切面]
  → target.save()         // 真实对象
```

客户端持有的是**代理 P**，不是原始 Bean——这也是 FactoryBean 场景里「P 在源码中没有固定实现类」的原因。

---

## 与 Spring 的对应

| 场景 | 动态代理在干什么 |
|------|------------------|
| **MyBatis `@Mapper`** | 接口无 Impl → 运行时 `$Proxy`，`selectById()` 转给 SqlSession |
| **Spring AOP / `@Transactional`** | 包一层代理 → 方法前后开/提交事务 |
| **`ProxyFactoryBean`** | 工厂 F 在 `getObject()` 里造代理 P |
| **`AbstractAutoProxyCreator`** | BPP 在初始化后自动包代理（注解 AOP 常用） |
