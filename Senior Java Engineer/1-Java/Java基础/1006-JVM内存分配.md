## 一句话概括

**Java 堆分配** 以 **TLAB 无锁 bump** 为快路径；refill / 大对象慢路径碰共享年轻区时需 **CAS 或锁**；年轻区满触发各 GC 的 Young 类回收；并发 GC 另靠 **空间隔离 + 屏障** 保证分配与移动不冲突。

# Part I：TLAB 机制

## 1. TLAB 是什么

**TLAB（Thread Local Allocation Buffer）** 是线程在年轻区（Eden / E Region / Small Page）内的一块 **私有缓冲区**。

```text
start ──→ top ──→ end
          ↑ bump 指针后移
```

| 作用 | 说明 |
|------|------|
| 无锁分配 | 小对象 `new` 只改本线程 `top`，无竞争 |
| 降低 CAS 频率 | 一次 refill 切出整块 TLAB，内含成千上万次分配 |

```bash
-XX:+UseTLAB          # 默认开启
-XX:+ResizeTLAB       # 按线程分配速率自适应大小（默认开）
-XX:TLABSize          # 手动指定（生产通常交给 JVM）
-XX:TLABWasteTargetPercent=1
```

---

## 2. TLAB 内分配：不需要 CAS

```text
if (top + size <= end) {
    ptr = top;
    top = top + size;   // 线程私有，无 CAS、无锁
    return ptr;
}
```

**TLAB 内 bump 不需要 CAS**，因为 `top` 只有本线程访问。

---

## 3. TLAB 不够时怎么办

```text
new 对象
  ↓
当前 TLAB 够吗？
  ├─ 是 → bump（无锁）
  └─ 否 ↓
      对象 > TLAB 上限？
        ├─ 是 → Eden/Page 慢路径（CAS/锁，绕过 TLAB）
        └─ 否 → 废弃 TLAB 尾部，refill 新 TLAB
                    ↓
              年轻区还有空间？
                ├─ 是 → 分配成功
                └─ 否 → 触发 Young 类 GC → 重试
```

### 3.1 尾部浪费

```text
TLAB 剩 30B，要分配 64B → 不够
剩余空间低于 waste 阈值 → 丢弃尾部，申请新 TLAB
用空间换速度，避免频繁同步
```

### 3.2 Refill 需要 CAS

向 **共享年轻区** 切新 TLAB 时，多线程竞争全局分配指针：

```text
do {
    old_top = eden_top;
    new_top = old_top + tlab_size;
} while (!CAS(eden_top, old_top, new_top));
```

| 场景 | 是否 CAS |
|------|----------|
| TLAB 内 bump | **否** |
| Refill 新 TLAB | **是**（或锁） |
| 大对象慢路径 | **是**（或锁） |

### 3.3 PLAB（类比）

Young GC 时 GC 工作线程并行复制晋升，用 **PLAB**（Promotion LAB）减少 worker 间竞争——与 TLAB 思路相同，面向 GC 线程。

# Part II：分配安全

## 4. 要防哪些安全问题

```text
1. 多线程分配竞争     多线程同时 bump 同一块年轻区
2. 分配 vs 回收冲突   GC 正在搬/清，线程还在往里 new
3. 移动 vs 读写冲突   对象已搬走，引用仍指向旧地址
4. 标记 vs 写引用冲突 GC 误回收仍被引用的对象（漏标）
```

四层机制：

```text
空间隔离  →  新对象不分到「正在收」的区域
线程隔离  →  TLAB / PLAB
屏障协调  →  读写引用时记录或修正（并发 GC）
```

> **易混**：此处「屏障」指 **GC 读/写屏障**（回收正确性），与 [[1007-内存屏障与Java内存模型]] 中的 **JMM 内存屏障**（线程可见性）不同。

```text
STW 卡点  →  Safepoint + 极短/完整停顿
```

---

## 5. Safepoint 与 GC Locker

### Safepoint

```text
触发 GC 前，所有线程到达 Safepoint
→ 避免「分配到一半」或「半更新引用」时 GC 开跑
→ 四种收集器均依赖
```

### GC Locker

```text
JNI GetPrimitiveArrayCritical 等可能推迟 GC
→ 滥用可导致 GC 堆积、STW 变长甚至 OOM
```

---

## 6. 四种 GC 的安全策略

| 安全问题 | **Parallel** | **G1** | **ZGC** | **Shenandoah** |
|----------|-------------|--------|---------|----------------|
| 多线程分配 | TLAB + 同步 | TLAB + 同步 | TLAB + 同步 | TLAB + 同步 |
| 分配 vs 回收 | **全 STW** | CSet 外 Region | 非 relocation Page | 非 evacuation Region |
| 移动 vs 读写 | **全 STW** | **STW evacuation** | 读屏障 + 染色指针 | 读屏障 + Brooks |
| 标记漏标 | **全 STW** | 写屏障 + SATB | SATB | SATB |
| 屏障开销 | **无** | 写屏障 | 读屏障 | 读屏障 |

```text
Parallel：回收时停世界，无需屏障
G1：搬家时 STW，并发标记用写屏障
ZGC / Shenandoah：并发移动，必须读屏障
```

详见 [[1004-G1垃圾回收与堆内存]]、[[1005-ZGC垃圾回收与堆内存]]。

# Part III：各回收器怎么分配

> 共性：**TLAB bump → refill（CAS）→ 慢路径 → Young 类 GC**。差异在年轻区物理形态与大对象去向。

## 7. Parallel（Throughput Collector）

JDK 8 服务端默认：**Parallel Scavenge + Parallel Old**。

### 7.1 堆布局

```text
┌────────── Young（连续）──────────┬────────── Old（连续）──────────┐
│  Eden  │  S0  │  S1              │  长期存活对象                   │
└──────────────────────────────────┴──────────────────────────────┘
```

可用 `-Xmn`、`-XX:NewRatio` 控制年轻代比例。

### 7.2 分配路径

```text
new → TLAB bump（Eden 内，无锁）
  → 不够 → refill（Eden CAS）或慢路径（大对象）
  → Eden 满 → Young GC（STW，复制到 S/O）
  → Old 满 → Parallel Old GC（STW，标记-整理）
```

### 7.3 特点

| 点 | 说明 |
|----|------|
| 分配目标 | **连续 Eden** |
| 大对象 | Eden 慢路径；`-XX:+PretenureSizeThreshold` 可直达 Old |
| 屏障 | **无** |
| 吞吐 | 通常最高，停顿随堆变差 |

---

## 8. G1（Garbage-First）

JDK 9+ 默认。详见 [[1004-G1垃圾回收与堆内存]]。

### 8.1 堆布局

```text
[E][E][S][O][H][F][O][E]...
 E=Eden  S=Survivor  O=Old  H=Humongous  F=Free
```

### 8.2 分配路径

```text
new → TLAB bump（E Region 内）
  → 不够 → refill / 新 E Region（从 Free 池）
  → 所有 E 用尽 → Young GC（STW，evacuation E+S）
```

### 8.3 Humongous

```text
对象 > RegionSize × 50%
  → 不走 TLAB
  → 从 Free 拿 H Region（可能多个）
  → 语义上进老年代
```

### 8.4 特点

| 点 | 说明 |
|----|------|
| 基本单位 | **等大小 Region** |
| 空闲来源 | **Free Region 池** |
| 年轻代 | `G1NewSizePercent` / `G1MaxNewSizePercent`，**不用 -Xmn** |
| 并发标记期 | 写屏障 + SATB |

---

## 9. ZGC

详见 [[1005-ZGC垃圾回收与堆内存]]。

### 9.1 堆布局

```text
[Small 2MB][Small][Medium 32MB][Large][Small]...
```

### 9.2 分配路径

```text
new → TLAB bump（Small Page 内）
  → 不够 → refill / 新 Small Page
  → 中等对象 → Medium Page（慢路径）
  → 大对象 → Large Page（独占，绕过 TLAB）
  → 分配压力 → 年轻代 GC 或完整 ZGC 周期
```

### 9.3 并发 Relocation 期

```text
新对象 → 非 relocation 的 Page
读引用 → 读屏障 + 染色指针
分配跟不上 → Allocation Stall（gc.log 可查）
```

---

## 10. Shenandoah

Red Hat 低延迟 GC，分配路径 **类 G1**。

### 10.1 堆布局

```text
[S][E][E][O][F][O]...   Region 网格
```

### 10.2 分配路径

```text
new → TLAB bump（E Region 内）
  → 不够 → refill / 新 E Region（Free 池）
  → 大对象 → 专用 Region，绕过 TLAB
  → Eden 用尽 → 年轻代 GC 或完整 Shenandoah 周期
```

### 10.3 并发 Evacuation 期

```text
新对象 → 非 evacuation 的 Eden Region
读引用 → 读屏障 + Brooks 转发指针
```

### 10.4 分代 Shenandoah（JDK 23+）

年轻代高频轻收 + 老年代完整周期，与分代 ZGC 思路平行。

---

## 11. 四种回收器分配对照

| 维度 | Parallel | G1 | ZGC | Shenandoah |
|------|----------|-----|-----|------------|
| 年轻区 | 连续 Eden | E Region 集合 | Small Page | E Region 集合 |
| TLAB 位置 | Eden 内 | E Region 内 | Small Page 内 | E Region 内 |
| TLAB 内 | 无锁 bump | 无锁 bump | 无锁 bump | 无锁 bump |
| refill | Eden CAS | Region CAS | Page CAS | Region CAS |
| 超大对象 | 慢路径/直达 Old | Humongous Region | Large Page | 大对象 Region |
| 年轻区满 | Young GC STW | Young GC STW | 年轻代/完整 GC | 年轻代/完整 GC |

### 分配路径简图

```text
Parallel:    new → TLAB(Eden) → Eden CAS → Young GC STW

G1:          new → TLAB(E Region) → 新 E Region(Free) → Young GC STW

ZGC:         new → TLAB(Small Page) → 新 Page → 年轻代 GC / ZGC 周期

Shenandoah:  new → TLAB(E Region) → 新 E Region(Free) → 年轻代 GC / 完整周期
```

### 同步成本（性能视角）

```text
最优   TLAB bump           纳秒级，无锁
中等   refill / 慢路径     CAS + 可能切 Region/Page
最慢   触发 GC             毫秒级 STW
       Allocation Stall    ZGC/Shenandoah 压力大时
```

# Part IV：运维与速记

## 12. 常见现象排查

| 现象 | 可能原因 |
|------|----------|
| Young GC 极频 | 分配太快、年轻区偏小 |
| 大量 Outside TLAB | 对象偏大；JFR `ObjectAllocationOutsideTLAB` |
| Humongous / Large 多 | 大数组、大 JSON、非流式序列化 |
| refill 竞争多 | 线程多、TLAB 偏小、对象尺寸分布不佳 |
| Allocation Stall | ZGC 堆小或分配突发 |

---

## 13. 面试速记

1. **TLAB 内 bump 不需要 CAS**，线程私有 `top`。
2. **Refill / 大对象慢路径** 碰共享年轻区，需要 **CAS 或锁**。
3. TLAB 不够：**废弃尾部 refill** → 仍不够则 **慢路径** → 年轻区满则 **Young GC**。
4. **Parallel** 连续 Eden，无屏障，回收全 STW。
5. **G1** E Region + Free 池；> Region×50% → Humongous。
6. **ZGC** Small/Medium/Large Page 分级。
7. **Shenandoah** 类 G1 Region 分配 + Brooks 读屏障。
8. 分配安全：**TLAB + 空间隔离 + 屏障（并发 GC）+ Safepoint**。
9. **PLAB** 是 GC 线程版的 TLAB，用于并行复制晋升。
10. 生产通常 **不手调 TLAB**，交给 `ResizeTLAB` 自适应。
