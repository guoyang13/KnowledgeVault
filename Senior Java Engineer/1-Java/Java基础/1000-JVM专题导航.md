### 路径 B：GC 与内存（性能调优 / 线上排查）

```text
1006 内存分配  →  1004 G1  →  1005 ZGC
```

```text
1006  TLAB、CAS、分配安全、Parallel/G1/ZGC/Shenandoah 分配路径
```

## 概念关联

```text
类加载线：
  双亲委派（1001）→ SPI 打破委派（1002）→ TCCL 桥接（1003）

内存线：
  TLAB 分配（1006）→ G1 Region 回收（1004）→ ZGC Page 回收（1005）

交叉点：
  Metaspace ← 类加载（1001）≠ 堆（1004/1005/1006）
  ServiceLoader ← 用 TCCL（1003）加载 SPI 实现（1002）
  内存屏障（1007）← JMM：volatile/锁/CAS 的可见性与有序性
  GC 读/写屏障（1004/1005/1006）← 回收正确性，与 1007 不同概念
```
