# CSAPP 核心术语索引

这份术语索引用来快速回忆概念，不替代章节笔记。

## 基础表示

bit：
最小信息单位，只能表示 0 或 1。

byte：
字节，通常由 8 个 bit 组成。

word：
机器字，CPU 自然处理的数据宽度，常见 32 位或 64 位。

endianness：
字节序，多字节对象在内存中的字节排列方式，分大端和小端。

two's complement：
补码，现代计算机常用的有符号整数表示方式。

overflow：
溢出，运算结果超出固定位宽可表示范围。

IEEE 754：
浮点数表示标准，定义了单精度、双精度、无穷、NaN、舍入等规则。

NaN：
Not a Number，表示无效或不可表示的浮点结果。

## 程序执行

ISA：
指令集架构，定义机器指令的语义和程序可见状态。

microarchitecture：
微体系结构，CPU 内部如何实现 ISA。

clock signal / clock cycle / clock rate：
时钟信号、时钟周期、主频。晶振驱动的节拍方波，同步寄存器与流水线；主频 = 每秒周期数。详见 [[04-处理器体系结构#CPU 时钟]]。

CPI / IPC：
Cycles Per Instruction / Instructions Per Cycle。每条指令平均占用周期数 vs 每周期完成指令数；实际性能 ≈ 主频 × IPC。

register：
寄存器，CPU 内部高速小容量存储。

program counter：
程序计数器，指向下一条要执行的指令。

stack frame：
栈帧，函数调用期间保存局部变量、返回地址和部分寄存器状态的区域。

calling convention：
调用约定，规定函数参数、返回值、寄存器保存等规则。

pipeline：
流水线，把指令执行拆成多个阶段并重叠执行。

branch prediction：
分支预测，CPU 猜测条件分支方向以提前执行。

hazard：
流水线冒险，导致流水线不能安全继续的情况。

## 性能和缓存

locality：
局部性，程序倾向于访问最近使用过或相邻位置的数据。

temporal locality：
时间局部性，最近访问过的数据可能再次被访问。

spatial locality：
空间局部性，访问某地址后可能继续访问附近地址。

cache line：
缓存行，缓存和内存之间传输的基本单位。

cache hit：
缓存命中，需要的数据在缓存中。

cache miss：
缓存未命中，需要从更低层存储加载数据。

CPE：
Cycles Per Element，每个元素平均消耗的 CPU 周期。

Amdahl's Law：
Amdahl 定律，系统整体加速受限于无法被优化的部分。

## 链接和加载

object file：
目标文件，包含机器代码、数据、符号和重定位信息。

symbol table：
符号表，记录函数、变量等符号及其位置。

relocation：
重定位，链接时修正代码和数据中的地址引用。

static linking：
静态链接，把库代码复制进最终可执行文件。

dynamic linking：
动态链接，在加载或运行时解析共享库。

PIC：
位置无关代码，可加载到不同地址仍能正常运行的代码。

loader：
加载器，把可执行文件映射到进程地址空间并启动执行。

## 操作系统

process：
进程，操作系统对运行中程序的抽象。

context switch：
上下文切换，保存当前执行状态并恢复另一个执行状态。

exception：
硬件/系统层面的异常控制流，不等同于 Java 异常。

interrupt：
中断，来自外部设备的异步事件。

trap：
陷阱，有意触发的控制转移，系统调用常通过它实现。

signal：
信号，操作系统发送给进程的异步通知机制。

system call：
系统调用，用户程序请求内核服务的接口。

## 虚拟内存

virtual address：
虚拟地址，程序看到的地址。

physical address：
物理地址，真实内存中的地址。

address space：
地址空间，进程可见的虚拟地址集合。

page：
页，虚拟内存和物理内存管理的固定大小块。

page table：
页表，记录虚拟页到物理页的映射。

page fault：
缺页异常，访问的虚拟页不在物理内存中时触发。

TLB：
Translation Lookaside Buffer，地址翻译缓存。

mmap：
内存映射，把文件或匿名对象映射进虚拟地址空间。

fragmentation：
内存碎片，分配器管理空间时产生的浪费。

garbage collection：
垃圾收集，自动回收不再可达对象的机制。

## I/O 和网络

file descriptor：
文件描述符，进程内引用打开文件、设备或 Socket 的整数。

inode：
文件系统中的元数据对象，描述文件属性和数据位置。

redirection：
重定向，改变标准输入输出对应的文件描述符。

socket：
网络通信端点，应用通过它进行网络 I/O。

TCP：
可靠、有序的字节流传输协议。

DNS：
域名系统，把域名解析为 IP 地址。

network byte order：
网络字节序，通常是大端。

I/O multiplexing：
I/O 多路复用，一个线程或进程同时监视多个 I/O 描述符。

## 并发

concurrency：
并发，多个任务交错推进。

parallelism：
并行，多个任务在同一时刻执行。

thread：
线程，进程内部的执行流，共享进程地址空间。

critical section：
临界区，访问共享资源且需要同步保护的代码区域。

race condition：
竞态条件，结果依赖不受控制的执行顺序。

semaphore：
信号量，用计数控制并发访问资源。

mutex：
互斥锁，同一时刻只允许一个执行流进入临界区。

deadlock：
死锁，多个执行流相互等待，导致都无法继续。

thread safety：
线程安全，多线程访问下仍能保持程序正确性。
