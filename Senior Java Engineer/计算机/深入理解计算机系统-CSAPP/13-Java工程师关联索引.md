## 建议掌握程度

必须掌握：

- 位、字节、补码、浮点数。
- 进程、线程、虚拟内存。
- 文件描述符、Socket、系统调用。
- 缓存局部性、上下文切换、锁竞争。

需要理解：

- 汇编和寄存器模型。
- 链接和加载。
- 页表和 TLB。
- 流水线和分支预测。

可以了解：

- Y86-64 细节。
- 硬件控制语言 HCL。
- 具体处理器电路实现。

## 面试表达模板

如果被问“为什么 Java 工程师要懂计算机系统”，可以这样回答：

> Java 运行在 JVM 上，但 JVM 运行在操作系统和硬件上。性能、内存、I/O、网络、并发问题最终都会落到 CPU、缓存、虚拟内存、系统调用、文件描述符和调度机制上。理解这些底层模型，能帮助我更准确地定位线上问题，而不是只停留在框架层。
