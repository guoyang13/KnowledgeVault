# DDIA 中英文术语对照

> 用途：统一笔记中的概念命名。后续阅读时优先使用“中文规范名”，首次出现可写成“中文规范名（English, 缩写）”。完整定义、机制与边界见 [[05-概念定义详解]]。

## 命名规范

| 规则 | 写法 |
|---|---|
| 首次出现 | `中文规范名（English, 缩写）`，例如：`复制延迟（replication lag）` |
| 后续出现 | 优先用中文规范名，例如：`复制延迟` |
| 行业内常用缩写 | 可直接保留缩写，但需要在本表能查到，例如：`WAL`、`LSM`、`MVCC`、`CDC` |
| 不建议混写 | 不要一会儿写 `partition`，一会儿写 `分片`，一会儿写 `shard` |
| 有多个中文译名 | 以“中文规范名”为准，别名放到“别名/缩写”列 |
