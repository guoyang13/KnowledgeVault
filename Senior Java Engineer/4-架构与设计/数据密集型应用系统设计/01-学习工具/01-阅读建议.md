# DDIA 阅读建议

> 如何读《数据密集型应用系统设计》：路径、节奏、与笔记配合方式。**不要求写阅读日志**——以章节精读里的练习与阅读检查自测即可。

## 读这本书的目标

| 不要 | 要 |
|---|---|
| 背 NoSQL、CAP、Kafka 名词 | 理解**权衡**：可靠性 / 扩展 / 维护 / 一致 / 延迟 |
| 大段抄 PDF | 用笔记里的**定义、案例、FAQ** 对照理解 |
| 一次读完 892 页 | 按 Part 或按问题**分阶段读** |

## 三条阅读路径

### 路径 S：快速掌握主干（约 2–3 天）

先不追求逐页读完，而是先形成“能评审、能解释、能落地”的骨架。

```text
Day 1: [[06-核心概念精炼与掌握路线]]
       → [[03-术语卡片]]（中英文规范名）
       → [[02-核心概念地图]]

Day 2: [[00-逐章精读总览与索引]] 的 12 章重读卡片
       → 第5、6、7、8、9章的「初学者先抓住一句话」和「核心概念定义」

Day 3: [[04-架构设计决策清单]]
       → [[01-Java后端与DDIA概念对照]]
       → 用一个真实模块做设计能力自测
```

**适合**：先用更短时间掌握全书主干，再决定哪些章节需要回 PDF 深读。

### 路径 A：架构师 / Tech Lead（推荐，约 4–6 周）

先建立「目标 → 事务 → 复制 → 共识」骨架，再补存储与流批。

```text
Week 1: 00-学习导航 → 02-核心概念地图 → 第1章精读
        → 05-概念定义详解（可靠性、性能指标）

Week 2: 第7章精读（事务、写偏斜）→ 03-事务一致性与分布式共识

Week 3: 第5章 → 第6章 → 02-复制分区与扩展性

Week 4: 第9章 → 第8章（故障）→ 04-架构设计决策清单

Week 5–6: 按需补 2–4 章（模型/存储/编码）、10–12 章（流批/集成）
```

**适合**：已有后端经验，要参与方案评审、选型、分布式问题排查。

### 路径 B：按书从头到尾（约 8–10 周）

```text
Part I  第1→4章  + 01-数据模型与存储选型
Part II 第5→9章  + 02-复制分区 / 03-事务共识
Part III 第10→12章 + 04-批处理流处理与数据集成
收尾   04-设计决策 + 05-工程落地 + 04-学习任务清单自测
```

**适合**：系统学习、第一次读 DDIA；配合 [[00-逐章精读总览与索引]] 每章「最小产出」。

### 路径 C：带着项目问题读（随时切入）

| 选型 MySQL / Mongo / ES | 第2章 + [[01-数据模型与存储选型]] | 第3章 |
| 读写分离、缓存不一致 | 第5章 + [[02-复制分区与扩展性]] | 第11章 CDC |
| 分库分表、热点 Key | 第6章 | [[02-复制分区与扩展性]] |
| 分布式事务、库存 | 第7章 + [[03-事务一致性与分布式共识]] | 第9章 |
| 超时、重复消费 | 第8章 | 第11章 |
| 报表拖垮 OLTP | 第3章 OLAP + 第10章 | [[04-批处理流处理与数据集成]] |
| 微服务拆库 | 第12章 | DDD 第13章集成 |

## 单次阅读怎么安排（2–3 小时一块）

```text
1. 先看 [[06-核心概念精炼与掌握路线]] 对应概念的“摘要 -> 精炼”
2. 查 [[03-术语卡片]]，统一本章中英文规范名
3. 打开 PDF 对应章 + 逐章精读里的「书中目录与小节映射」
4. 读精读「初学者先抓住一句话」+「核心概念定义」
5. 读 PDF 正文（不必逐字；重点看案例与权衡讨论）
6. 回到精读：「机制深度专题」「书中案例」「深度 FAQ」
7. 做本章「阅读检查」；可选做 1–2 道练习
8. 若做设计：扫一眼「设计模式与反模式」「架构设计检查清单」
```

**不必**：单独开文档记日志；**可以**：在 Obsidian 某章笔记下直接加自己的 `# 我的项目` 段落（可选）。

3. **[[04-架构设计决策清单]]** — 用真实模块走一遍评审清单

## 常见读法误区

| 误区 | 建议 |
|---|---|
| 跳过第1章直接看 Kafka | 先建立可靠性/延迟/负载语言 |
| 只读精读不翻 PDF | 案例细节与论证在原文 |
| 每章求 100% 记住 | 以「能评审、能选型」为准；术语查 [[03-术语卡片]] |
| 孤立读第7章 | 与第5章读保证、第9章分布式事务一起读 |
