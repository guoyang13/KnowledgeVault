# 常见场景技术选型速查

> 快速参考，非教条。具体以负载、团队、成本为准。

## 电商 / 供应链

| 场景 | 推荐模式 | DDIA 要点 |
|---|---|---|
| 下单 | 单库事务 + 订单聚合 | 第 7 章本地事务 |
| 库存扣减 | 单行乐观锁 / Redis Lua + 异步对账 | 防写偏斜 |
| 订单状态跨服务 | Saga + 领域事件 | 第 9、11 章 |
| 采购单导入 | 幂等 batch + Outbox | 第 11 章 |
| 商品搜索 | MySQL 真相 + ES 索引 + CDC | 第 12 章 |
| 报表 | T+1 数仓，禁止 OLTP 大查询 | 第 3、10 章 |

## 账户 / 支付

| 场景 | 推荐 | 避免 |
|---|---|---|
| 余额变更 | 单库 Serializable 或串行队列 | 跨库 2PC |
| 对账 | 批处理 + 差异告警 | 仅最终一致无对账 |
| 重复支付 | 幂等键 + 唯一索引 | 纯前端防重 |

## 社交 /  feed

| 场景 | 推荐 | 要点 |
|---|---|---|
| 发帖 | 写主库，读可 lag | 读己之所写走主 |
| 时间线 | Fan-out on write / read 权衡 | 第 6 章分区 |
| 计数 | 异步聚合 / HyperLogLog | 最终一致 |

## 配置 / CMS

| 场景 | 推荐 |
|---|---|
| 结构化 + 半结构化 | PostgreSQL JSONB |
| 纯文档 | MongoDB |
| 多环境发布 | Git + 配置中心，版本化 |

## 日志 / 监控

| 场景 | 推荐 |
|---|---|
| 应用日志 | ELK / Loki |
| 指标 | Prometheus |
| 链路 | OpenTelemetry |
| 审计 | 不可变日志 + 长期存储 |

## 缓存策略

| 模式 | 适用 | 风险 |
|---|---|---|
| Cache-aside | 通用 | 穿透/击穿/雪崩 |
| Read-through | 统一缓存层 | 复杂度 |
| Write-through | 强一致缓存 | 写延迟 |
| **CDC 更新** | 搜索/缓存视图 | 管道运维 |

## Java 技术栈速配

| 需求 | 组件 |
|---|---|
| OLTP | MySQL + MyBatis/JPA |
| 缓存 | Redis + Redisson |
| MQ | RocketMQ / Kafka |
| 搜索 | Elasticsearch |
| 分库 | ShardingSphere |
| 分布式事务 | **优先 Outbox**；慎用 Seata XA |
| CDC | Canal / Debezium |
| 批 | Spark / Spring Batch |
| 流 | Flink（重度）/ Kafka Streams |

## 何时上 Kafka

- 需要 **多消费者** 独立读同一日志
- 需要 **重放** 构建新视图
- 流量削峰、解耦

不必上：简单点对点、低 QPS、团队无运维能力。
