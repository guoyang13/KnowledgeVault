# 采购订单服务 DDD 第二版

本目录集中保存采购订单服务第二版的领域设计和可编译 Java 伪代码。

第二版在第一版替换路线的基础上，重新核对了原业务代码，并调整了限界上下文、聚合边界、履约模型、质量模型、结算模型和查询模型。涉及领域归属和聚合行为时，以本目录内容为准。

## 3. 伪代码工程

[scm-purchaseorder-next-service](../project/README.md) 位于上级目录的 `project/` 中，是第二版设计对应的可编译 Java 伪代码，包含：

- 七个限界上下文的聚合、状态机和领域事件。
- PR 数量预占与转 PO。
- 采购路线计算。
- 供应商履约、质量检验和采购结算。
- 履约要求、执行任务、异常和订单旅程。
- 查询投影、Outbox 和内存适配器。
- 端到端场景及架构边界测试。

## 4. 与第一版的关系

上级目录中的 `00` 到 `08` 保留替换阶段、迁移、影子运行、分流和旧服务下线等第一版演进资料。

使用原则：

- 服务替换节奏和迁移治理可以继续参考第一版。
- 限界上下文、聚合边界、命令、事件和工程实现以第二版为准。
- 第一版中由 `PurchaseOrder` 直接管理发货、收货、入库的设计不再采用。
