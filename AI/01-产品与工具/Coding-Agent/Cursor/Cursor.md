# Cursor

> AI-first IDE，围绕代码库上下文、Agent 模式和编辑器内工作流提供编程辅助。

## 关键点
- **形态**：IDE 内 Agent，可读写项目文件、运行命令、解释代码和生成补丁。
- **优势**：贴近编辑器状态，适合重构、补全、代码问答和小到中等规模任务。
- **关注点**：上下文选择、权限控制、模型选择、变更审查。
