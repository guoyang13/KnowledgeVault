# 安全与治理导航

## 当前主笔记

[[AI/00-AI学习体系/02-概念库/07-安全治理/01-Prompt Injection与Agent安全|Prompt Injection与Agent安全]]：区分直接/间接注入、Jailbreak、工具滥用和数据泄露，并建立多层防护。

## 安全分层

| 层级 | 主要措施 |
|---|---|
| 输入与内容 | 来源标记、数据/指令分离、注入检测 |
| 上下文 | 最小必要信息、敏感数据隔离、记忆治理 |
| 工具 | 最小权限、参数校验、允许列表、沙箱 |
| 动作 | 高风险操作审批、幂等、事务和回滚 |
| 输出 | 隐私过滤、事实校验、来源与不确定性 |
| 运营 | Trace、审计、红队、事故响应和回归 Eval |

## 核心原则

```text
Prompt 负责提醒，代码负责强制；
模型负责建议，权限系统决定能否执行；
自动化程度越高，越需要可观察、可中止和可追溯。
```
