## 工程分层

```text
产品目标与 Eval
→ Workflow / Agent 编排
→ Context / RAG / Memory
→ Model / Tool / MCP
→ Runtime / Serving / Observability / Security
```

框架只是实现手段。选型前先明确状态、分支、工具、权限、持久化和评测需求；简单任务优先使用直接 API 和普通代码。
