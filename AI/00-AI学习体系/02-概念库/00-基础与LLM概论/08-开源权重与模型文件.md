# 开源权重与模型文件

> 更新时间：2026-07-08。
> 这组概念是理解「Llama / Qwen / DeepSeek / Mistral 开源」、本地部署、微调的前提。

## 一句话

**开源权重 = 公开发布的模型参数文件**；你可以下载、本地部署、微调，但不等于训练数据和训练过程也完全公开。

## 「开源权重」四个品牌指什么

| 品牌 | 出品方 | 典型开源系列 | 常见用途 |
|---|---|---|---|
| **Llama** | Meta | Llama 3 / 3.1 / 4 Scout·Maverick | 西方生态、私有化、微调基座 |
| **Qwen** | 阿里 | Qwen2.5 / Qwen3 dense·MoE | 中文、代码、Agent、RAG |
| **DeepSeek** | 深度求索 | V3 / R1 / V4、R1-Distill 小模型 | 推理、性价比、MoE |
| **Mistral** | Mistral AI | Mistral 7B、Mixtral、Magistral Small | 欧洲生态、企业私有化 |

它们共同点是：**权重可下载**；License 各自不同（多为 MIT 或带附加条款），商用前需读 LICENSE。

## 模型权重文件是什么

权重文件 = 训练结束后保存的**神经网络参数**，不是代码，不是对话记录，而是大量浮点数：

```text
0.01234, -0.5678, 1.234e-4, ...
```

- **7B** ≈ 70 亿参数；**671B** ≈ 6710 亿参数（MoE 总参数，不等于每次推理全激活）。
- 常见格式：`.safetensors`、`.bin`、`.gguf`（Ollama / llama.cpp 常用）。
- 大模型常分片：`model-00001-of-00005.safetensors`。
- 推理还需要配套：`config.json`、`tokenizer.json`、`generation_config.json`。

### 类比

| 类比 | 对应 |
|---|---|
| 人脑神经连接强度 | 权重参数 |
| 把学会的东西固化 | 保存成文件 |
| 恢复记忆 | 加载权重文件 |
| 游戏安装包 | 权重文件（还不能玩） |
| 游戏引擎 + 启动 | 推理框架（Ollama / vLLM） |

## 权重文件 vs 本地可运行大模型

```text
可下载的模型参数（原材料）
    +
模型结构代码 + Tokenizer
    +
推理引擎（Ollama / vLLM / llama.cpp）
    ↓
可本地部署、可对话的大模型服务
```

| | 权重文件 | 本地部署的大模型 |
|---|---|---|
| 形态 | 磁盘上的静态文件 | 加载后正在推理的运行实例 |
| 能否直接对话 | ❌ | ✅ |
| 需要什么 | 存储空间 | 权重 + 推理软件 + GPU/内存 |

## 开源权重 vs 闭源 API

| | 开源权重 | 闭源 API（如 GPT-4 API） |
|---|---|---|
| 能否拿到模型文件 | ✅ | ❌ |
| 能否本地/内网部署 | ✅ | ❌ |
| 数据是否出网 | 可控 | 通常要走公网 |
| 运维成本 | 自己管 GPU | 厂商托管 |

## 权重文件能否「重新训练」

可以，但要分清层次：

| 类型 | 含义 | 谁在做 |
|---|---|---|
| **微调（Fine-tuning）** | 在已有权重上继续训 | 个人、小团队、企业（主流） |
| **继续预训练** | 用大量文本继续「读书」 | 有中算力团队 |
| **从零预训练** | 随机初始化训 671B | 仅大厂 |

个人/公司说的「训练」，几乎都是 **在开源权重上微调**，不是从零训 DeepSeek 级别模型。
