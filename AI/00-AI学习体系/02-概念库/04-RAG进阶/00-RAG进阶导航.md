## 最小链路

```text
文档 → 清洗与分块 → Embedding → 索引
查询 → 召回 → 重排 → 上下文组装 → 生成 → 引用与评测
```

## 关键边界

- RAG 改变模型本轮看到的资料，不改变模型参数。
- Embedding 负责相似度表示，不等于生成模型的词向量查表。
- 检索到内容不代表内容正确；仍需来源、权限和新鲜度控制。
- GraphRAG 适合关系密集和全局问题，不是普通 RAG 的默认升级。
- Agentic RAG 用灵活性换取更多调用、成本和不可预测性。
