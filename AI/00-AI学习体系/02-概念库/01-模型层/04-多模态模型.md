# 多模态模型（Multimodal / Omni）

> 原生支持文本 + 图像 + 音频 + 视频的统一模型，不再是"文本模型 + 单独的视觉/语音模块"。

> 2026-07 更新：多模态已经从“看图问答”扩展到实时语音、视频生成/理解、屏幕操作、PDF/文档解析、多模态 embedding 和 Computer Use。

## 关键点
- **Native Multimodal**：输入输出共享同一 token 空间，相比"视觉编码器拼接"方案泛化更好。
- **Vision**：ViT / Sigmoid-Loss ViT（SigLIP）→ 多分辨率切片 → 任意尺寸图像。
- **Audio**：编码为离散 token（Whisper-style 或 codec token）。
- **Video**：抽帧 + 时间编码 / 视频 token。
- **Any-to-Any / Omni**：图文音视频任意输入输出（GPT-4o、Gemini）。
- **Multimodal Reasoning**：推理模型 + 多模态（看图做几何题、看截图操作 GUI）。

## 代表模型
- **OpenAI GPT-5.x / GPT-Realtime / GPT Image**：文本、图像、语音、工具和 computer use 逐渐平台化。
- **Gemini 2.5 / 3 系**：文本、图像、音频、视频、Live API、Veo、Imagen/Nano Banana、multimodal embedding。
- **Claude 4 / 5 系**：文本和图像输入，面向代码、长任务和 agentic workflow。
- **Llama 4 Scout / Maverick**：开放权重、原生多模态、MoE。
- **Qwen-VL / Qwen-Omni / Qwen3 系**：中文生态中的多模态与 Agent 能力重要路线。
- **InternVL、LLaVA、MiniCPM-V**：开源视觉语言模型生态。
